Student Registration Form

A simple student registration form available in two versions:

Java (Swing) desktop app — Main.java
Browser version — index.html

Both let you enter a student's name, gender, department, address, and skills, then submit the entry.

Features
Text field for student name
Radio buttons for gender (Male / Female)
Dropdown for department (Computer Science, Information Technology, Software Engineering)
Text area for address
Checkboxes for skills (Java, Python)
Submit — adds the entry to a running list
Clear — resets the form fields (does not remove already-submitted entries)
Exit — closes the app (Java) / tells you it's safe to close the tab (browser)
Running the Java version

Requires a JDK installed.
